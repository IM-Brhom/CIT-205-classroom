# ACE Professional Portfolio Template

Student portfolio starter for CIT 205 / ACE Support Command.

## Portfolio sections
- Home / About
- Missions
- Tickets
- Knowledge Base
- Validation & Troubleshooting
- Skills & Evidence

## Launch
1. Create your own repository from the class template or GitHub Classroom assignment.
2. Edit `index.html` with your name, professional introduction, goals, and first evidence entry.
3. Commit your changes with a professional commit message.
4. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
5. Open the published site and verify it on desktop/mobile.

## Evidence pattern
For each artifact use: **Context → Action → Evidence → Result / Reflection**.

## Never publish
Passwords, secrets, tokens, private URLs, PII, customer/student records, or sensitive infrastructure details. Use sanitized, redacted, or synthetic evidence.

## Course capability map
- Workstation validation
- Ticketing
- Knowledge-base authoring and review
- Troubleshooting
- Professional communication
- Mission proposal

This portfolio is designed to continue growing in later CIT/SOTE courses and later support résumé, LinkedIn, and interview development.
